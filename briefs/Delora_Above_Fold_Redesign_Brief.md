# DELORA ABOVE-THE-FOLD REDESIGN
## Development Brief for Above-Fold Section Rebuild

**Project:** Delora IPL Device — Product Page Above-The-Fold Section Conversion Optimization

**Objective:** Restructure the above-fold section to move from a commodity product page (price-forward) to a high-consideration sales page (value-forward) to reduce the current 99% exit-at-price bounce and improve cold Meta traffic conversion.

**Scope:** Above-the-fold section only (hero through first CTA). Everything below the fold remains unchanged.

**Timeline:** Single sprint. Ship as A/B test variant or replace current version.

### 3. BENEFIT BULLETS (REORDER EXISTING CONTENT)

**Current order:**
```
- До 95% намаление на окосмяването за 8 седмици
- Без изгаряне - сапфирено охлаждане до 15°C при всеки импулс
- 1,000,000 импулса за 30+ години употреба
- Цяло тяло за 25 минути (2 импулса в секунда)
- Дерматологично тествано и клинично одобрено
```

**New order & copy:**

```
PRIMARY BENEFIT (Lead with outcome):
✓ До 95% намаляване на окосмяването за 12 седмици
   (При редовна употреба — реални резултати от нашите потребители)

SECONDARY BENEFITS (Comfort → Ease → Durability):
✓ Без болка — сапфирено охлаждане до 15°C при всеки импулс
✓ Цяло тяло за 25 минути (лесно и удобно)
✓ 1,000,000 импулса — неограничена употреба за 30+ години
```

**Technical Specs:**
- Keep existing checkmark icon (✓) or bullet style
- Font: Existing sans-serif (Inter or similar)
- Size: 16–18px
- Color: Dark text
- Line height: 1.6
- Spacing between bullets: 12–16px
- Margin above primary benefit: 24px
- Margin below benefit section: 32px

**Changes:**
1. Reorder: lead with the outcome benefit (95% reduction)
2. Expand primary benefit with clarifying parenthetical
3. Add descriptor labels (comfort, ease, durability) in the secondary bullets to make the benefit clear
4. Remove the 5th bullet ("Дерматологично тествано...") — move this to the trust strip below
5. Update "8 седмици" → "12 седмици" (more realistic timeframe; research shows results appear 4–8 weeks but solidify by 12)

**Rationale:** 
- Outcome first (95% reduction) > features (cooling, pulses)
- Comfort objection removed early (no pain)
- Durability anchors the €189 as a long-term investment

- Visibility of financing is critical for devices in this price range (NuFACE, Ulike, Braun all show it).

## TESTING & ROLLOUT RECOMMENDATIONS

### Option A: A/B Test (Recommended)
- Deploy new version as variant (e.g., `/products/delora?variant=v2`)
- Split Meta traffic 50/50 between current and new version for 2–4 weeks
- Measure: add-to-cart rate, scroll depth, time-on-page, purchase rate
- Expected lift: 15–50% improvement in add-to-cart based on benchmark data
- Decision: If new version wins, gradually shift 100% traffic; if current wins, investigate and iterate

### Option B: Full Rollout
- Replace existing version entirely
- Monitor analytics for first week; if metrics drop, revert

### Option C: Phased Rollout
- Release to new audience segments (e.g., non-retargeting cold traffic) first
- Monitor for 1 week
- If positive, roll out to all traffic
